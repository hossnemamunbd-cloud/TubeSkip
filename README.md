# TubeSkip – YouTube Video Blocker

TubeSkip is an Android app designed to help users block unwanted and inappropriate YouTube videos and create a safer viewing experience, especially for children.

## Features

* Block unwanted YouTube videos
* Help filter inappropriate content
* Simple and easy-to-use interface
* Lightweight Android application
* Privacy-focused design
